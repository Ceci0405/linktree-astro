# Linktree con Astro

## Instalar y arrancar
```bash
npm install
npm run dev
```
Abre http://localhost:4321

## Personalizar
- Edita `src/data/links.js` para cambiar tu nombre, bio y enlaces.
- Sube tu foto a `public/avatar.jpg`.

## Desplegar gratis
```bash
npm run build
```
Sube la carpeta `dist/` a Netlify, Vercel o GitHub Pages (arrastrar y soltar en Netlify es lo más rápido).
